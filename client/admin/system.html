Encrypted database & media backups

Backups contain BSON documents, indexes, local/catalog media and cloud image bytes. New writes pause while a consistent backup is captured. Restores target a new isolated database and media directory.

Backup and restore commands

Run from server/ after configuring your private backup encryption key. Keep the key separately from the backups.

npm run backup:create
npm run backup:verify -- --file /absolute/path/to/backup.ndb
npm run backup:restore -- --file /absolute/path/to/backup.ndb --database norda_restore_review123 --output /absolute/path/to/new-restore-folder

See docs/PRODUCTION_TOOLS.md for scheduled backups, off-host copies and safe restore promotion. This screen never exposes archive contents or encryption keys.
